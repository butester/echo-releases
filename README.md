### Intelligence that runs on your computer

**Qwen powers Echo locally.** Start with the everyday model, or download the larger 14B option for slower, deeper reasoning. Your conversations stay in your Windows user profile, with no publisher account or conversation sync.

Sensitive actions ask first. Code edits stay inside your selected project and keep local backups. Echo Code does not automatically execute code or terminal commands.

### Get started

1. **[Download the latest release](https://github.com/butester/echo-releases/releases/latest)** and run the `Echo-Setup` installer for Windows x64.
2. Review the Privacy Policy and Terms, then set up the local model. Initial setup needs internet and several GB of free storage; model speed depends on your hardware.
3. Start a conversation, attach a document, or switch to **Echo Code** and choose a project folder.

**Already installed?** In Echo 0.3.1 or later, open **Settings → Updates → Check now**, then **Restart and update**. Earlier versions need one manual install. Updates retain your conversations, settings, and downloaded models.

<summary><strong>Privacy, downloads & Windows signing</strong></summary>

- Chat inference, document extraction, OCR, and code processing run locally. Echo does not upload your conversations or project files to the publisher.
- Model downloads, update checks, and live weather require their respective online services. Weather uses the coordinates you configure. See the full Privacy Policy for details.
- Updates use a publisher-signed release announcement and installer integrity checks. You choose when to restart and install.
- Installers are signed by **Butepowered** with a **self-signed certificate**. Windows may show an unknown-publisher or SmartScreen warning; the certificate is not automatically trusted on other computers.
- OCR may make mistakes. Long-document summaries can cover excerpts rather than the whole file. Copy-restricted or password-protected PDFs are not bypassed.
- This repository hosts official downloads and release information. GitHub’s automatically generated “Source code” archives contain this release repository, not the Echo application source.
